Installing a C++ Compiler

Visual Studio Code (VS Code) is an editor, not a compiler. To build and run C++ programs, you must install a C++ compiler appropriate for your operating system.

Important: Installing VS Code alone is not enough to compile C++ programs. You must also install a compiler such as GCC or Clang.

Windows

  1. Install MSYS2 (recommended) or MinGW-w64.
  2. Follow the installation instructions provided by the compiler vendor.
  3. Open a terminal or command prompt after installation.
  4. Verify the compiler is installed by entering:
g++ --version

macOS

  1. Open the Terminal application.
  2. Run the following command:
xcode-select --install
  1. Follow the prompts to install the Xcode Command Line Tools.
  2. Verify installation:
g++ --version

Linux

  1. Install GCC using your distribution's package manager.
  2. Examples:
# Ubuntu / Debian
sudo apt install g++

# Fedora
sudo dnf install gcc-c++

# Arch Linux
sudo pacman -S gcc
  1. Verify installation:
g++ --version
Verification: If a version number is displayed, your compiler is installed correctly. If you receive an error such as "command not found," revisit the installation steps for your operating system.
Next Step: After installing a compiler, return to VS Code and install the Microsoft C/C++ extension to enable syntax highlighting, code completion, and debugging support.
