unit testing

Unit testing verifies that individual functions behave as expected.

The assert macro checks that a condition is true. If the condition is false, the program will terminate with an error message. 


#include <cassert>

int add(int a, int b) {
    return a + b;
}

int main() {
    assert(add(2, 3) == 5);
    assert(add(-1, 1) == 0);
    return 0;
}
