Getting Started with C++ in Visual Studio Code (VS Code)

Important: Visual Studio Code (VS Code) is not the same product as Visual Studio.

VS Code has a lightweight editor that can be customized with extensions. Visual Studio is a larger, full-featured Integrated Development Environment (IDE) that includes many tools and features already built in.

Visual Studio Code (VS Code) is a lightweight development environment that relies on extensions to provide support for specific programming languages and technologies. For example, you can install extensions for C++, HTML, CSS, JavaScript, Java, Python, C#, and many other languages. This modular design allows developers to install only the tools they need for a particular project.

Install VS Code and a C++ Compiler

Download and Install Visual Studio Code

  1. Open a web browser and go to:
    https://code.visualstudio.com
  2. Download the version appropriate for your operating system.
  3. Run the installer.
  4. Accept the default installation options.
  5. Launch Visual Studio Code when installation is complete.

Install a C++ Compiler

VS Code provides editing features, but you must also install a C++ compiler.

  • Windows: Install MinGW-w64 or MSYS2 GCC.
  • macOS: Install Xcode Command Line Tools.
  • Linux: Install GCC using your package manager.

Verify installation from a terminal:

g++ --version
Configure VS Code for C++ Development

Install Recommended VS Code Extensions

  1. Open VS Code.
  2. Select the Extensions icon from the left toolbar.
  3. Install the following extensions:
  • C/C++ (Microsoft)
  • C/C++ Extension Pack (optional)
  • Error Lens (optional)
  • Code Runner (optional)
Note: Extensions provide language-specific features such as syntax highlighting, code completion, debugging support, and error detection.
Create a Simple C++ Program

Create a Project Folder

  1. Create a new folder named HelloWorld.
  2. Open VS Code.
  3. Select File → Open Folder.
  4. Open the HelloWorld folder.

Create a Simple C++ Program

  1. Select File → New Text File.
  2. Save the file as hello.cpp.
  3. Enter the following program:
#include <iostream>

int main()
{
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
  • Save the file (Ctrl+S or Cmd+S).

    • Edit and Save the Program

    Make a simple change to the output message, such as replacing Hello, World! with your own text.

    Example:

    std::cout << "Welcome to CIS Programming!" << std::endl;

    Save the file after making your changes.

    Build and Run the Program
    1. Open a terminal in VS Code:
      • Menu: Terminal → New Terminal
    2. Compile the source file:
    g++ hello.cpp -o hello

    If there are no errors, an executable file will be created.

    Run the Program

    Windows:

    hello.exe

    macOS / Linux:

    ./hello

    You should see your output displayed in the terminal.

    Test Your Program

    1. Change the output text.
    2. Save the source file.
    3. Recompile:
    g++ hello.cpp -o hello
    1. Run the program again.
    2. Verify that the output reflects your changes.

    Common Compile and Run Cycle

    g++ hello.cpp -o hello
./hello
    Caution: For this course, write portable Standard C++ code whenever possible. Avoid using precompiled headers such as pch.h or stdafx.h, and avoid IDE-specific files and project dependencies that may be automatically created by some development tools. Your source code should compile using a standard C++ compiler from the command line without requiring Visual Studio project files, proprietary libraries, or generated configuration files.
    Best Practice: Submit only the files your instructor requests, typically the .cpp source files. Do not submit generated executables, temporary files, build folders, or IDE configuration files unless specifically instructed to do so.
